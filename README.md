# popspace-legal

Rechtliche Seiten für popspace (AGB, Datenschutz, Impressum, Nutzungsregeln). Gehostet via GitHub Pages.

- `index.html` — Startseite mit Links
- `agb.html` — AGB (Zustimmung bei der Registrierung), mit Widerrufsbelehrung im Anhang
- `privacy.html` — Datenschutzerklärung
- `imprint.html` — Impressum
- `terms.html` — Nutzungsregeln (Teil der AGB, § 5)

## Deploy

Auf GitHub Pages aktiviert. Nach Push automatisches Deployment über den `main` Branch.
