# popspace-legal

Rechtliche Seiten für popspace (Datenschutz, Impressum, Nutzungsregeln). Gehostet via GitHub Pages.

- `index.html` — Startseite mit Links
- `privacy.html` — Datenschutzerklärung
- `imprint.html` — Impressum
- `terms.html` — Nutzungsregeln (Zustimmung bei der Registrierung)

## Deploy

Auf GitHub Pages aktiviert. Nach Push automatisches Deployment über den `main` Branch.
